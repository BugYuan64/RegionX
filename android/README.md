# RegionX · Android

Kotlin + Jetpack Compose 的屏幕截图问答应用。默认全屏截图，也可在设置中切换为可移动、缩放的区域识别框。任务、截图、回答和追问历史保存在本机。

## 运行环境与构建

- minSdk 29（Android 10），compileSdk / targetSdk 36（Android 16）。
- Kotlin 2.3、Compose Material 3、SQLite、OkHttp / SSE、MediaProjection。
- API Key 与附加请求头由 Android Keystore AES-GCM 加密；不依赖远程账户服务。
- 本机已验证 JDK 21、Gradle 8.14.3、SDK 36。工程目前使用外部 Gradle，未附 Wrapper。

```powershell
gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease
```

中文工程路径会将构建目录重定向到 `%TEMP%/regionx-gradle-build/app`，避免 Gradle 测试 classpath 编码问题。默认英文路径仍使用 `app/build`。本机 Kotlin 增量缓存跨盘时可添加 `-Pkotlin.incremental=false`。

可安装测试包位于 `publish/RegionX-android-debug.apk`，包名 `com.regionx.app.debug`；`RegionX-android-release-unsigned.apk` 是经过 R8 和资源压缩的未签名 Release，需要正式签名后安装。两者的摘要见 `publish/SHA256SUMS.txt`。

## 使用

1. 打开「设置 → 上游」，展开下拉框，点末项「添加配置」。填写接口类型、地址、API Key 与默认模型名，保存。
2. 下拉框点选配置即可切换唯一启用的上游。每一项右侧的「编辑」进入同一个编辑页；添加时使用初始默认值。已有配置会保留。
3. 「设置 → 通用 → 截图方式」可选「全屏截图（默认）」或「区域截图（可调整识别框）」，点「保存通用设置」生效。旧设置中没有该字段时默认全屏。
4. 回到历史会话点「开始识别」，允许悬浮窗和共享整个屏幕。每次点击均新建一条历史会话；已有有效录屏授权时直接复用，无需再次授权。全屏模式显示问答、队列、退出三个小球；区域模式额外显示可拖动和四角缩放的识别框。
5. 点右侧问答球，截图并创建独立问答任务，显示「问答任务已创建，已加入队列」。截图期间隐藏所有悬浮 UI，连续点击可在前一任务运行时继续创建任务；截图操作本身串行。
6. 点问答球内侧的 6dp 三角按钮，读取当前上游模型列表。面板为 173×187dp（原宽、高的约 2/3），可滚动；按球上、下可用空间决定展开方向。当前模型右侧打勾，点其他模型用于后续新任务。Gemini 标识使用不依赖 SVG 圆弧解析的星形路径。
7. 三个球窗口高 40dp，问答球连同三角触发区宽 58dp；球体均可长按拖动，松手吸附最近的左、右、上、下可用屏幕边缘并保存位置，三角始终朝屏幕内侧。点退出球需确认后关闭悬浮窗和录屏会话。
8. 点队列球弹出 173×187dp 的当前会话列表，与模型列表等大，可滚动；标题、预览和点击区域同步增大。每项标题是创建日期和时间，小字为回答第一行，超出宽度显示省略号；历史会话中的任务采用同样的标题、预览规则。
9. 点任务打开可关闭的悬浮对话窗，只显示当前任务的截图、完整回答和追问，不再显示同一会话的其他任务模块。支持软键盘输入；阅读时暂时收起区域框，避免遮挡对话。队列球右上角显示未读的已完成任务数；展开队列后，点击关闭按钮或再次点击队列球，会把当前会话所有已完成任务标为已读并清除角标，滚动区外的任务也包括在内。打开单个任务仍只消费该任务的完成版本；截图、旋转、切回主界面等内部收起不批量已读。读状态在重启后保留，后续新任务或重试的新完成结果仍计为未读。
10. 任务完成与失败不再发送系统通知，也不再请求通知权限。录屏前台服务仍按 Android 要求调用常驻服务通知；翻译、提取、置顶按钮不再显示，浮窗保持置顶。

模型切换不会改写配置保存的默认模型，也不会改变已提交任务的模型快照；重试和追问沿用该任务的模型。切换启用上游时清除之前的临时模型选择，恢复新上游的默认模型。列表接口失败时保留当前模型并提供重试。

## Android 行为与限制

| 情况 | 行为 |
| --- | --- |
| 常驻悬浮控件 | 使用系统应用悬浮窗，始终置顶；系统授权页、安全界面仍可主动隐藏应用悬浮窗。 |
| 全屏操作 | 不显示识别框，独立接口直接保存完整录屏帧，不使用识别框坐标裁剪；任务记录保存实际 PNG 尺寸。 |
| 区域模式 | 整框拖动，四角缩放；区域窗口内触摸用于操作识别框。 |
| 打开主界面 | 自动收起悬浮界面，服务与队列继续；再次点「开始识别」会新建会话并显示悬浮球，旧任务继续处理并保留在原会话。 |
| 截图会话 | 授权后立即启动唯一 VirtualDisplay，避免授权后等待过久才首次创建；同尺寸连续截图复用 reader/surface，缓存最新帧，并按隐藏浮窗时的帧时间边界排除旧画面。 |
| 授权结束 | 主界面提示重新授权；点击「开始识别 · 重新授权」会新建会话，旧会话保留。缺图、空文件或不支持图片的模型会明确报错，不再降级发送纯文字请求。 |
| 任务提醒 | 通过队列球角标和队列中的已读/未读显示，不发送任务通知。 |
| 退出与后台 | 退出只关闭截图界面，不主动取消已提交任务；当前应用进程继续处理。系统强制回收进程时，未完成任务会在下次启动恢复为取消状态，可手动重试。 |
| 安全窗口 | `FLAG_SECURE` 页面可能截成黑屏，属于系统限制。 |

三种模型协议仍支持 OpenAI 兼容、Claude、Gemini。历史翻译/提取任务及配置字段继续兼容读取，新界面只创建问答任务。Windows 源码与交互保持独立。

## 目录与数据

```text
app/src/main/java/com/regionx/app/
├─ core/       模型与设置、LLM 适配器、任务队列、截图/文本规则
├─ data/       SQLite、配置仓库、凭据加密、任务已读版本
├─ platform/   屏幕录制授权与截图
├─ overlay/    可选区域框、三个悬浮球、模型/任务面板、对话、退出确认、服务
└─ ui/         历史会话、任务详情、设置与主题
app/src/test/  单元及 Robolectric / MockWebServer 回归测试
tools/         本机假模型服务与清理测试数据脚本
publish/       APK、摘要与交付说明
```

应用私有 `files/` 下保存 `models.json`、`settings.json`、`screenassistant.db`、`images/`、`logs/`。与 Windows 的表结构和既有配置字段兼容；Windows 的 `dpapi:` 密文无法在 Android 解密，需要重新填写 Key。新增加的 Android 设置字段不影响旧文件读取。
